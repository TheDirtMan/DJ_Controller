This is the embedded software for a DJ MIDI controller.

This repository contains my HardwareWrapper library, which is only tested on my exact hardware, but you are free to use it. There will not be a separate repository for that library.

This repository also contains a MIDIWrapper library, which will likely only work on a Teensy. There will not be a separate repo, but if you want to use it, go ahead.

This code is running on a Teensy 4.0.
